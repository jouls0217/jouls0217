### 🧠 About Me

I'm a developer who bridges **business logic with infrastructure** — building reliable systems from the ERP layer all the way down to the deployment pipeline.

- 🧩 **Odoo ERP** — custom modules, QWeb reports, multi-company setups
- ☁️ **AWS Cloud** — deploying and maintaining production sites on **EKS**, managing container images via **ECR**, and monitoring infrastructure costs with **Cost Explorer**
- ⚙️ **DevOps** — Docker, CI/CD pipelines, NGINX reverse proxies, automated backups
- 💻 **MERN Stack** — full-featured REST APIs and React frontends

> I aim for **clean, modular, and maintainable** systems — whether it's an Odoo module, a containerized deployment, or a scalable API.
